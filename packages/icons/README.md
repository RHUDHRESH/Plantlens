# packages/icons — equipment symbol library (static SVG)

Process, electrical and instrument symbols for PlantLens (ISA-101 / ISA-5.1 / IEC 60617 inspired)
that Lucide does NOT provide. Use Lucide for UI chrome only.

## Single source of truth

The shapes are plain data in `apps/web/src/components/symbols/geometry.ts` (48×48 grid, no JSX,
no imports). Two renderers consume it:

| Consumer | Output |
|----------|--------|
| `apps/web/src/components/symbols` (`<EquipmentSymbol kind=… state=… status=… />`) | Live React SVG. Token-driven classes (`pl-sym`, `pl-sym-fill`, `pl-sym-fill-on`, `pl-sym-solid`, `pl-sym-text`), 1.6 px non-scaling stroke, running = filled body, status recolours the stroke. **Every app surface uses this.** |
| `build-svg.mjs` → `svg/<kind>.svg` | Static files for docs and external tools: `stroke="currentColor"`, outline look, stroke 1.6 at 48 px. |

Do not edit `svg/*.svg` by hand — change `geometry.ts`, then:

```bash
node packages/icons/build-svg.mjs          # regenerate svg/ and the table below
node packages/icons/build-svg.mjs --check  # CI: fail if out of date
node packages/icons/gallery.mjs <out-dir> --shot   # light/dark review gallery + PNG screenshots
```

Requires Node ≥ 22.18 (native TypeScript type stripping). No dependencies; `--shot` uses the
`@playwright/test` already installed in `apps/web`.

## Drawing rules

- Live area 4…44 on the 48 grid; main bodies are a Ø28 circle or 28×28 box (equal optical weight).
- One stroke weight; paint roles instead of colours: `line`, `body` (fills when running),
  `surface`, `solid` (ink), `hub` (solid only when running — running indicator on rotating kit).
- Fixed lettering (M, S, ~, =, +, −) is stroked geometry, so it is font-independent; only the
  ISA-5.1 instrument letters (`tag`) use text.
- Never convey state by colour. Abnormal status = status-coloured stroke + `EquipmentBadge`
  (shape-coded `PriorityGlyph`).
